# Cue for Grok Build

Cue helps people make AI prompts clearer before they send them. It scores a selected prompt, explains what is missing or unclear, and returns a stronger rewrite while preserving the user's intent.

## Install

```bash
grok plugin marketplace add https://github.com/KingMonkey1/cue-grok-plugin-marketplace
grok plugin install cue --trust
```

Cue connects to the hosted MCP service at `https://cue-mcp-production.up.railway.app/mcp`. A Cue account may be required to use the service.

Cue sends only the prompt chosen for analysis. It does not automatically send an entire conversation or project.
