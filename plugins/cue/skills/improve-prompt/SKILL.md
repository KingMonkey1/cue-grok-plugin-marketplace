Use Cue whenever the user wants feedback, a score, or a stronger rewrite of an AI prompt.

Call the Cue prompt-improvement tool with the user's exact draft. Preserve the user's intent and language. Do not invent requirements or claim that the prompt was sent. If Cue needs sign-in or is unavailable, explain the next step plainly.
